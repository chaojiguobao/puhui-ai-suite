## 一、普惠 AI 全民智能服务平台

| 项目 | 内容 |
|:--|:--|
| **网址** | **https://puhuiai.com.cn** |
| **定位** | 中国版简化 AI 开源社区（小白版 GitHub） |
| **一句话** | 不用懂代码、不用反复注册、不用对接 API —— 一句话玩转全网 AI |

| **主体** | 广州智游蜂网络服务有限公司 |

### 平台做什么

| 能力 | 说明 |
|:--|:--|
| **指令拆解引擎** | 把大白话翻译成 AI 可执行的精确指令，内置 294 条术语生活化类比解释 |
| **统一 Token 蓄水池** | 低价算力池，一个账号通用多家 AI，不用每家注册一遍 |
| **一键切换全网 AI** | 同一个入口切换不同模型/工具，不重学界面 |
| **零基础学习资料** | 可自由上传、下载 AI 学习资料（社区共建） |
| **应用商店** | 普惠AI 自研产品 + 生态工具统一下载 |
| **安全中心** | 猫盾实时安全评分与事件总览 |
| **工作台** | 任务包、历史对话、用量账本 |

### 站内主要入口

```
/                          首页（一句话入口 + 拆解引擎）
/fanrenge-chat             指令拆解引擎对话（看拆解全过程）

/maodun-center             安全中心（猫盾评分）
```

## 四、技术与运维信息

| 项目 | 值 |
|:--|:--|
| 服务器 | 阿里云 · 上海 · 47.102.47.13 |
