## 一、这是什么

普通人和 AI 之间隔着一道"术语墙"：你想说的是"帮我把这份行程单整理得好看点"，AI 要的是"请以 Markdown 表格输出，列为：日期/城市/交通/住宿，按时间升序"。

**普惠AI 指令拆解引擎就是把前者翻译成后者**。它内置 **294 条术语生活化类比解释**，所有专业词自动转成大白话，让你不用学提示词也能把 AI 用明白。

**适用人群**：完全不懂技术的普通人、想用 AI 提效但被提示词劝退的小商家、刚接触 AI 的学生和退休人群。

## 二、核心功能

### 1. 双向翻译（核心）
- **人话 → 指令**：你说"帮我写个朋友圈文案，卖云南旅游"，它输出可直接执行的结构化指令
- **术语 → 人话**：看到"embedding / RAG / 温度参数"不懂，它用生活类比解释给你听

### 2. 294 条术语库
覆盖 AI 领域常用词：模型、提示词、Token、微调、向量、智能体、工作流……每条都有**生活化类比**，不堆定义。

### 3. 任务拆解（不只是回你一段文字）
你说一个大目标，它拆成"步骤1 → 步骤2 → 步骤3"，并给出每步的**可执行动作**，直接拿去用。

### 4. 统一入口（一号通全 AI）
一个账号，统一调用多家 AI 能力，不用每家注册一遍、不用自己对接 API。平台侧提供**统一 Token 蓄水池**（低价算力池），用多少算多少。

### 5. 插件版（给你的 AI 装上这个能力）
`puhuiai-plugin-v1.3.1.zip` 可以装进你自己的 AI 工具（小龙虾 / Hermes / 任意支持插件的 Agent），**零算力、离线可跑、不占你的 token**。

### 6. 学习资料库
平台可上传/下载零基础 AI 学习资料（中国版简化 AI 开源社区思路：小白版 GitHub）。

## 三、工作原理

```
你的一句大白话
      ↓
① 意图识别      判断你要的是「写作 / 翻译 / 查询 / 分析 / 自动化」
      ↓
② 术语映射      294 条术语库：把口语词映射到标准 AI 概念
      ↓
③ 指令组装      按目标模型的要求拼成结构化指令（角色/任务/约束/输出格式）
      ↓
④ 执行 & 回报   调用模型执行，把结果用人话回给你
      ↓
⑤ 任务包落盘    可复用的任务拆解包（下次同类活直接调）
```

**关键设计**：拆解与执行分离 —— 翻译层不绑定某一家模型，所以平台可以统一调度、随时换模型而不影响你的使用方式。

## 四、操作使用说明书

### 方式 A · 网页版（推荐新手，零安装）

1. 浏览器打开 **[puhuiai.com.cn](https://puhuiai.com.cn)**
2. 首页搜索框直接输入大白话，例如：
   > 帮我写一条卖云南旅游的朋友圈文案，要有点紧迫感
3. 点「拆解」→ 看到它给出的结构化指令 + 执行结果
4. 想看拆解过程的每一步：进入「普惠AI指令拆解引擎对话」页
5. 常用指令可存成「任务包」，下次一键复用

### 方式 B · 桌面版（离线/批量用）

1. 下载 `puhuiai-chaijie-v4.0.0.exe`
2. 双击安装；Windows 提示"未知发布者"→ 更多信息 → 仍要运行
3. 首次启动填入 API Key（平台账号里可复制）
4. 主界面左侧三个入口：**拆解对话 / 任务包 / 术语库**
5. 输入大白话 → 回车 → 右侧出「可执行指令」+「执行结果」

### 方式 C · 插件版（装进你自己的 AI 工具）

1. 下载 `puhuiai-plugin-v1.3.1.zip`
2. 解压到你的 AI 工具的插件目录（如 小龙虾 / Hermes 的 plugins 目录）
3. 重启你的 AI 工具，在技能列表里确认「普惠AI指令拆解」已加载
4. 之后你在那个工具里说大白话，它会自动先走拆解

## 五、常见问题

**Q1 要不要懂提示词？**
不用。它存在的意义就是让你不懂也能用。你只管说人话。

**Q2 免费吗？**
软件免费。调用 AI 模型会产生 token 费用，平台提供**统一 Token 蓄水池**（比你自己一家家买便宜），按量计费。

**Q3 和直接问 ChatGPT/DeepSeek 有什么区别？**
直接问：你得自己把话说清楚，说不清就得到一堆废话。
普惠AI：它先帮你把话"翻译"成 AI 听得懂的精确指令，再执行，并给你可复用的任务包。

**Q4 我的数据会被拿去训练吗？**
不会。对话内容仅用于本次任务；平台不出售、不用你的数据训练模型。

**Q5 插件版和桌面版什么关系？**
桌面版 = 独立软件（自带界面）；插件版 = 给别的 AI 工具加装这个能力（无界面，零算力）。两者能力同源。

**Q6 支持哪些模型？**
平台侧统一调度，当前主力 DeepSeek 系列，可切换；具体可用模型以站内「模型」页为准。
