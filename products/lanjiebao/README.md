## 一、这是什么

每天三五通推销、贷款、诈骗电话：接起来闹心，直接拒又怕漏掉快递、医院、孩子学校。

拦接宝把「接不接」变成「先看是谁」：**陌生号先被问一句"您是哪位"，对方回复即留话；通讯录里的人照常响铃，一通不漏。**

**适用人群**：被骚扰电话困扰的普通成年人、不会判断诈骗的老人、怕漏接孩子学校来电的家长。

## 二、核心功能

| 来电类型 | 你的手机 | 对方 |
|:--|:--|:--|
| 通讯录 / 白名单里的人 | **正常响铃**（跟没装一样） | 正常听到回铃音 |
| 陌生号码 | 不响，事后 App 里看到留言卡片 | 收到"请问您是哪位"的问询，回复即算留言 |

| 带高危前缀（如 +110 / 00110） | 红色横幅提示"疑似改号伪造，勿转账" | — |

**卡片上的四个动作**：回拨 / 加入白名单 / 忽略 / 拉黑。加入白名单后，这个号码下次直接响铃。

**明确不做的事**（重要）：
- ❌ 不自动拨号、不回拨、不冒充任何号码
- ❌ 不录制你的正常通话（只录对方在云端的留言，且录音前有语音告知）
- ❌ 不上传你的通讯录（仅本机使用）
- ❌ 不自动拉黑任何人（拉黑永远是你点的那一下）

## 三、工作原理（三层）

### ① 手机这一层：谁免检，系统说了算

安卓有一个系统级来电筛查服务（`CallScreeningService`），它**只对"不在通讯录里的号码"触发**。所以"白名单 = 通讯录成员"就等于系统级免检 —— 家人、客户、快递，一个都不会被拦。

### ② 运营商这一层：把陌生来电"转"到云端

陌生号码来时 App 不接，改由运营商把这一通**遇忙转移**到云端号码：

| USSD 指令 | 作用 |
|:--|:--|
| `**67*云端号码#` | 遇忙转移（App 内「一键设呼转」，约 2 秒生效） |
| `**61*云端号码#` | 无应答转移（响铃 5–30 秒后转） |
| `##002#` | 一键取消全部呼转（随时可退，不用卸载） |

### ③ 云端这一层：接起来、问一句、留个话

云端接起 → 播提示语（含录音告知）→ 录音 → 语音转文字 → 生成摘要 → 推送到你手机 App 的「留言中心」。

```
来电
 ├─ 通讯录/白名单 ──► 直接响铃（不经云端 · 0 资费 · 0 延迟）
 ├─ 陌生号码 ──────► App 不接 ──► 运营商遇忙转移 ──► 云端问询+留言+录音
 │                                                   └─► 转文字 ─► 推送 App
 └─ 紧急短号 110/119/120/122/96110 ──► 强制响铃 + 官方标记（绝不转走）
```

### ④ 断网/云端故障怎么办

App 连续 3 次心跳失败 → 提示"留言服务不可用" → **一键关闭呼转** → 陌生来电恢复默认响铃。
设计原则：**宁可不拦，也不漏接。**

## 四、操作使用说明书

### 第一步 · 安装（约 2 分钟）

1. 下载 `lanjiebao-v0.1.49.apk`
2. 提示"未知来源/风险应用"时选 **允许 / 继续安装**
3. **华为用户**若被「纯净模式」拦住：设置 → 安全和隐私 → 更多安全设置 → 纯净模式 → 关闭增强防护，装完可再打开

### 第二步 · 授权（这步不做，拦不住）

1. 打开 App，按首页提示点 **「设为默认电话应用」** 并确认
2. 给四个权限：**通讯录、电话、短信、通知**（缺一个就少一环）
3. 允许后台常驻：设置 → 应用管理 → 拦接宝 → 电池 → 允许后台运行 / 关闭省电限制，并打开「自启动」

### 第三步 · 开呼转（一键）

1. App 首页 → **「一键设呼转」** → 按系统弹窗确认
2. 看到 **「✅ 设置成功」** 才算生效；若显示「⚠️ 设置未确认」，到拨号盘手动输入 `**67*云端号码#` 再拨号
3. 点「导入通讯录」把家人、常联系的客户一次性加进白名单

### 第四步 · 日常使用

- **陌生来电**：你手机不响；对方收到问询短信。对方回复后，App「留言中心」出现卡片（号码 · 归属地 · 时间 · 摘要 · 录音）
- **看到卡片**：回拨 / 加入白名单 / 忽略 / 拉黑
- **想临时关掉拦截**：拨 `##002#` 取消全部呼转即可，不用卸载

### 第五步 · 卸载前必做

> ⚠️ **先取消呼转，再卸载。** 拨号盘输入 `##002#` → 拨号；或 App 内「取消全部呼转」。
> 直接卸载会导致陌生来电继续被转走而没人接。

## 五、常见问题

**Q1 会不会漏掉快递、医院、学校？**
对方回复一条短信就成留言，你能在 App 里看到；把常用号码提前加白名单，他们直接响铃。

**Q2 收费吗？**
App 免费。可能产生的是**运营商呼转费**（转第三方号码一般 0.1–0.3 元/分钟，多数套餐含免费留言信箱）；常用号码加白名单就不走呼转，不花钱。

**Q3 老人能用吗？**
能用。建议先帮他把子女、亲属、常去医院、社区电话一次性导入白名单；拦截后他只需要点「回拨」。

**Q4 会不会偷偷录音？**
不会。只录对方在云端的留言，播放提示语时会明确告知"本次通话将被录音"；你的正常通话不录。

**Q5 为什么 110 能打进来？**
110/119/120/122/96110 在强制放行名单里，永远响铃并标记为官方短号，不会被转到云端。

**Q6 换手机怎么办？**
新手机重新做「第二步授权 + 第三步设呼转」；旧手机卸载前记得拨 `##002#`。

**Q7 装完发现打不出去电话？**
检查是否被误设为"仅白名单可呼出"；到 App 设置里确认「呼出不受限」。
